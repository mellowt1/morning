# Paul's personal logo

PAO with the full name Paul Alexander Ortiz beneath, oxblood on cream, an Andean condor flying behind.
Picked 2026-10-06 on the Claude Design canvas "Paul personal logo" (https://claude.ai/artifact/PJ9DNEWrJHC7rKzDwjvfem, board "Chosen · PAO").
Letterforms are Archivo Black (SIL Open Font License) converted to outlines, so no font is needed.
